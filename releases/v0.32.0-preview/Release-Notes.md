# Performance Garden 0.32 preview

An animated garden for VIBE FM by Kid Bunka. Seven page families now have their own moving backgrounds; a soft bloom follows page changes; navigation and pad lights follow the garden palette; four Stage macros grow as plants. The reviewed firmware sound engine and parameter/state layout are unchanged from 0.31.

The instrument includes six generative tracks, 271 Biomes in 19 families, 16 performance pads, a gesture looper, moments, variations, 24 engines, filters and envelopes, modulation and Living Links, Drift, harmony and bass sequencing, a lo-fi kit, cloud/tape/echo/room effects, LISTEN/SING, Itinera, Journey, radio, MIDI learn, Stage, Dream Console, banks and contextual help. The illustrated English guide covers all 50 pages.

## Checks and limits

Exact WASM SHA-256: `7e92c85283bee8268253927ebc082e8b390ec722945d4122c4f8433fc89766b5`.

36 functional scripts and the SDK checker passed. AU/VST3 native integration passed 26/26 cases in anyDAW 0.3.61 with the documented **private host compatibility patch**. Project save/load, three automation lanes, a cold app restart and animated playback were checked in the complete app. These results do not establish VIBE hardware, MPC, FM-1 or SMK compatibility. Read `docs/anydaw-host-notes.md` before using VIBE 0.8.0 in an unpatched anyDAW host.

Install only in VIBE FM / its supported software host. Do not flash this WASM/ZIP as FM-1 or SMK firmware. Complete corresponding source is browsable at this release tag; GitHub also provides its source ZIP/TAR archives. Licences and third-party notices are retained.
